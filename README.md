# FLICK
> *Framework for the Legendary Intelligent Cesitar Kinetics*

FLICK es un framework modular de simulación y benchmarking para futbolín robótico enfocado en el aprendizaje por refuerzo y la transferencia Sim-to-Real. Integra un backend físico desacoplado, generación de datasets sintéticos, y entornos compatibles con Gymnasium para entrenar agentes en condiciones controladas pero realistas.
